## Reference Usage

When citing these standards in code or documentation:

1. **Use the new number** for active standards (e.g., "Standard 011" not "Standard 059")
2. **Add supersedes note** when referencing historical context (e.g., "Standard 011 (supersedes Standard 059)")
3. **Update code comments** that reference old standard numbers
